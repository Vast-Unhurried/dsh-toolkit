# dsh-session-nav — 对话节点导航条

DeepSeek Harness 原生风格的**会话窗口内**导航条：对话文字列与右侧滚动条之间的
右缘节点串，**每一条 user 提问（轮次）一颗短横条**——悬停预览、单击跳转并切换
置顶框内容、双击钉住、激活条跟随阅读位置。纯浏览器端插件（Node half 为空），
零数据通道、零核心改动。

设计参考：DeepSeek 官网文档页右侧滚动指示条 + [vlln/dsh-navbar](https://github.com/vlln/dsh-navbar)
的成熟交互模型，并按需求定制（圆胖极简 UI、磨砂玻璃置顶框、颜色随主题、位置贴
滚动条、短横条形态、物理反馈、常驻跟随会话切换）。

## 交互速查

| 操作 | 行为 |
|---|---|
| 悬停节点 | 短横条平滑加长（13px）+ 弹出预览卡（**该轮全部内容**，超高内部滚动，淡入动画） |
| 单击节点 | 平滑滚动跳转到该轮提问（目标条脉冲高亮），同时**置顶框内容切换为该轮全部内容**；历史轮次尚未加载进窗口时自动补页后跳转 |
| 双击节点 | **钉住/取消钉住**（**个数不限**）：仅高亮（全不透明 + 略加粗，**无蓝点**），持久化到 localStorage；轮次尚未加载时自动补页后钉住 |
| 单击插件区域以外 | 置顶框内容回到**最新一条**（只显示轮次序号 #N，**无「最新」字样**） |
| 滚轮（光标在节点串上） | 滑动节点串本身（**deltaY 累积 + rAF 每帧批量应用**，高精度滚轮也平滑如链条）——**最多同时显示 6 条**，超出部分滚轮查看 |
| 点击节点串空白处 | 跳到最近的节点并选中 |
| 点击置顶框 | 跳转到置顶框当前显示的那一轮 |
| 按下节点/置顶框 | 物理缩放反馈（:active） |

## 置顶框（顶部，磨砂玻璃）

- 位置：**滚动容器顶部**（注入滚动容器自身，sticky 相对真正的 scrollport，
  不受中间层 overflow 影响，滚动时始终吸顶），**宽度 = 对话框文字列宽
  左右各加长 2.5cm**（`--dsh-chat-content-width` 默认 748px + 共 5cm，
  居中对齐），**高度随内容自由伸展**（上限 70vh / 640px，超出内部滚动）；
- **背景为磨砂透明玻璃**：主题底色 40% 透明度 + `backdrop-filter: blur(24px)
  saturate(1.5)`（磨砂感重）+ 半透明描边 + lv2 阴影，圆角 16px；字体为
  **标准 DSH 字体**（随主题配色）；
- 内容 = **当前选中轮次的全部内容**（默认最新一条，无「最新」标签，
  **`#N` 序号与内容同一行、中间空一格**），**15px 加粗（600）**；
  单击短横条即切换，单击插件区域以外回到最新；
- 旧版（v4）的"累积芯片"模型已废弃，相关 localStorage 键自动清理。

## 视觉

- **节点形态 = 扁短横条**（9×3px 全圆角胶囊，非圆点；DeepSeek 官网
  指示条形态），悬停/激活时加长到 13px——"比短横条稍微长一点点"；钉住态
  11×4px；间距 20px、圆角 999px，整体圆润；
- **颜色随主题**：深色模式节点为白色，浅色模式为黑色（半透明为常态，
  悬停/钉住加满）；激活节点为 DeepSeek 蓝 + 微光；
- 预览卡为官方 HoverCard 同款实色卡片（280px / r16 / lv3 阴影，**显示
  全部内容**，最大 45vh 内部滚动）；
- **物理反馈**：悬停平滑加长、按下缩放、钉住 pop 动画、跳转脉冲、
  预览淡入；`prefers-reduced-motion` 下全部禁用；
- 全部使用 DSH 设计令牌（`--dsw-alias-*`、`--dsw-specific-*`、`--dsw-shadow-*`），
  自动适配深浅主题，符合 Harness 原生极简风格。

## 机制

- **轮次总数**：`sessions.list` 快照 `byId[sid].projectionValues.sessionStats.turns`
  （服务端统计，**含被压缩的历史轮次**，与底部状态栏「N 轮」同源）+ 会话
  `running` 时 +1（用户计数习惯把「这次对话」算进去，在途消息立即上条）；
- **user 行**：流项 `[data-chat-flow-key^="13:input-message"]` 且含
  `[class*="bubble"]`（上下文注入/steering 行无 bubble 自动排除；旧契约
  `[data-time-hover-root]` + bubble 作回退）；节点身份持久化用
  `data-chat-flow-key`（消息级 UUID），缺省回退文本前缀匹配；
- **虚拟化窗口**：对话流是窗口化渲染（约百项 + 「加载更早」分页，窗口固定
  锚定最新内容尾部）：**切换会话后未压缩内容立即显示**（约 1s 内出条，
  短横条数量来自服务端统计，不依赖 DOM）；压缩/未加载的历史轮次由
  **后台缓慢预载器逐页补齐**（每 2.8s 一页，读会话面 `loadingOlder`/`hasMore`
  门控，app 正在翻页或用户正在操作插件时让路，绝不排队堆积）；用户点选
  未加载轮次时按需快速补页（上限 6 次，app 忙时自动重试）；程序化点击
  不受「单击外部复位」影响（仅响应 isTrusted 的真实用户点击）；
- **流畅性（v13 优化）**：DOM 锚点（flow/scroller）、user 行列表（流指纹：
  元素 + 首/末子节点 + 子节点数，文本流式更新不失效）、钉住解析（sid+rows+
  offset+版本 四元组）三级缓存——滚动/流式期间的每次渲染成本趋近零；
  MutationObserver 只对对话流内结构变化触发；预载器带停滞防护（连续 6 次
  翻页无行数增长自动停止，绝不空转；**跨会话切换自动重置计数**，不会误判
  新会话为停滞）；apply 幂等（热重挂载自动重挂根元素）；
  置顶框增量渲染（选中未变时 DOM 零改动）；会话切换后约 1s 内出条；
- 会话切换/流重建由 MutationObserver + sessions 服务订阅驱动；启动后前
  2 分钟每 2s 兜底重渲染，杜绝任何漏检导致节点串不出现；
- 位置：节点串右缘 = 滚动条左缘 − 8px（动态测量滚动条宽度），垂直居中于
  滚动容器，且永不低于文字列右缘 + 12px；CSS 自带 `right:26px` 兜底位置，
  任何时刻都不会跑到视口外；
- 节点串**最多同时显示 6 条**（rail max-height 138px 内部滚动，隐藏滚动条；
  滚轮在节点串上 = 链条式滑动翻看，页面不滚动），激活条变化时自动滚入
  可视区（滚轮手动滑动后 1.5s 内不打扰）；**常驻**：≥1 轮即显示，切换
  会话自动跟随当前会话轮次数；
- 自检：`data-dsnav-version` 属性、console 日志与 `window.__DSNAV_DEBUG__`
  （含最近一次渲染错误）便于确认运行时状态。

## 安装

```sh
dsh plugin --profile web add "本地路径或 git 源"   # 装完重启 dsh web 生效
```

无配置项。卸载后自动清理全部 DOM 与监听器。

## 与其它插件共存

- `dsh-better-sidebar`：右侧面板展开时节点串跟随滚动容器左移，始终位于
  面板与文字之间，不重叠（z-index 900 仅在极端窄窗下兜底浮于其上）；
- `@vlln/dsh-navbar`：包名/id 不同，可并存。
