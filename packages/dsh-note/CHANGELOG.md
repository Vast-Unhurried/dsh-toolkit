# Changelog

## [1.3.0] - 2026-08-19

- 新功能：历史便签**双击内容即可行内编辑**，停止输入约 0.6 秒后**自动保存**
  （新增宿主方法 `updateHistory`：按 id 原地更新文字与时间戳、保持条目位置；
  输入期间的在途请求按序号守卫，新键入内容自动接续保存，不丢字）。
- 编辑中显示「编辑中… / 保存中… / 已自动保存」状态（错误红色显示原因）；
  按 ESC 结束编辑，收起条目或关闭窗口前也会先落盘；编辑中的条目暂停拖动。
- 编辑后的条目时间戳刷新，但**不改变列表位置**（手动排序不会被重排）。

## [1.2.2] - 2026-08-18

- 修复：草稿保存失败不再静默丢失（只有服务端确认成功才清除草稿标记）。
- 修复：关闭弹窗时在途保存的响应不再导致状态卡死「保存中」；每次重新打开弹窗都会重新加载草稿与历史（不再显示陈旧数据）。
- 修复：历史读取路径同样截断到 30 条上限。
- 安全加固：API 同源检查要求 Host 回环 + Origin 精确匹配（防 DNS rebinding 与任意本地端口页面）。

## [1.0.0] - 2026-08-16

首发。

- 输入框工具行（Full access 选择器右侧）新增与周边图标同款的便签按钮（`conversation.input.left` 插槽）。
- 打开即新建便签；「保存」归档进历史并清空编辑区；关闭弹层时未保存内容自动存草稿防丢（下次打开恢复）。
- 「历史便签」弹出独立窗口：可拖拽、可缩放、记住最近一次的位置与大小（localStorage）。
- 历史条目点击展开/收起，展开时显示「复制」按钮；每条可单独删除；上限 30 条；相同内容去重。
- 宿主路由 `POST /plugins/dsh-note/api`（getNote / setNote / commitNote / deleteHistory / ping）；数据落盘 `$DSH_HOME/storages/dsh-note.json`（原子写、串行化）。
