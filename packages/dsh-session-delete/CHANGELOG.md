# Changelog

## [1.0.3] - 2026-08-18

- 安全加固：API 同源检查要求 Host 回环 + Origin 精确匹配（防 DNS rebinding 与任意本地端口页面）。
- 安全加固：删除前 `realpath` 解析存储根并校验删除目标在根内（防符号链接逃逸）；存储根缺失时拒绝删除（不再静默假成功）。
- 错误信息不再回显完整磁盘路径细节。

## [1.0.2] - 2026-08-17

- 拒绝删除**运行中**的会话（先停止/关闭再重试），避免持久化写路径与删除操作竞态。
- 重名会话不再按 DOM 顺序猜测，拒绝并提示重试，避免误删。

## [1.0.0] - 2026-08-16

首发。

- 会话列表 ⋮ 菜单新增「删除会话」：彻底删除会话（JSONL 会话日志 + 工作区登记 + 归档集合）。
- 会话目录按持久化后端同款路径编码定位（`projectKey` / `encodeSegment`）；会话 ID 严格校验；删除成功后页面自动刷新。
- 宿主路由 `POST /plugins/session-delete/api`；确认弹窗走 `shell.overlay` 槽位。
